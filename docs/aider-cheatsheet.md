# Aider cheat sheet

- `/add <file>` — add a file to the context so Aider can read/edit it
- `/drop <file>` — remove a file from context
- `/undo` — undo the last Aider edit (rolls back its git commit)
- `/git <cmd>` — run a git command (`/git status`, `/git diff`)
- `/help` — list all commands
- `/exit` or `Ctrl+D` — quit
